Esc 지연된 화면 튐 수정 검증

더블클릭 → 입력 → Esc 뒤 자동 저장이 자기 쓰기를 외부 변경으로 잘못 알리면서 알림 줄이 잠깐 나타났다. 실제 데스크톱에서 읽기 화면의 y 좌표가 110 → 151 → 110으로 바뀌었다. DOM 스크롤 좌표만 검사하면 이 움직임을 놓친다.

자체 저장의 감시 처리를 정확한 저장 버전이 나온 뒤 재검사하도록 바꿨다. 다른 창과 실제 외부 교체·삭제, 실패한 저장은 계속 감지한다. 읽기 화면 전환과 준비 코드는 기존 경로를 유지한다. 실험 중 추가했던 전환 대기와 픽셀 캡처는 성능 저하가 확인되어 제거했다.

동일한 새 회귀 검사가 기준본에서 잘못된 외부 변경 알림과 네이티브 위치 110 → 152 → 110을 검출했다. 수정본은 180 Chromium 프레임 동안 최신 내용과 스크롤을 유지했고, 잘못된 알림은 없었다.

최종 수정본을 실제 데스크톱에서도 확인했다. Esc 최초 전환의 위치 적용 뒤 제목은 녹화 2.733초부터 y=308을 유지하며, 자동 저장 때 다시 움직이지 않았다. 최초 전환의 한 프레임 위치 조정까지 없다고 주장하지 않는다.
