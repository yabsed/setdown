# 미리보기 성능 비교

baseline `dc13af7` → 수정 빌드. 각 버전 3회 × 8개 시나리오 × 5회 전환. 단위는 ms이며 모든 칸은 baseline → 수정본이다.

첫 번째·두 번째는 독립 실행 간 중앙값이다. Warm은 각 실행의 3–5회 중앙값을 먼저 구한 뒤 실행 간 중앙값을 구한다. 준비 대기는 source에서 입력하기 전 기다리는 시간이며, 0과 3000 ms를 따로 비교한다.

Escape 측정에는 최신 내용 확인·IPC·native capture 읽기가 포함된다. 모니터의 실제 표시 시각을 뜻하지 않는다. 수정 시나리오는 최신 편집 내용이 보이는 캡처만 유효하다.

[원시 비교·각 실행의 표본·빌드/의존성/하네스 해시](benchmark/comparison.json). 양쪽 모두 `SETDOWN_BUILD_SOURCEMAP=0`으로 미리 빌드했고, 같은 Xvfb에서 AB/BA 순서를 교대로 실행했다. 실행 중 빌드나 하네스를 바꾸지 않았다. 이 결과는 전환 지연 비교이며 메모리 절감률 측정은 아니다.
