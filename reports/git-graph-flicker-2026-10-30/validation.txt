Git graph flicker fix — validation (2026-10-30, Asia/Seoul)

Cause: each replacement Git status snapshot invalidated the graph mount effect
even when the repository path was unchanged. Upstream refresh also rebuilt
unchanged rows and reset loaded pages. The pre-fix Electron regression lost
the selected row, details, keyboard focus and 2364px of scroll position.

Fix: derive the repository path separately; check history before public refresh.
Unchanged history retains DOM, focus, scroll, selections and loaded pages.
Renew cursors at the loaded depth. Coalesce bursts, retain a trailing check,
wait for filtering/paging, reject stale replies and abort on pane disposal.
Real commit/ref changes continue through upstream refresh.
