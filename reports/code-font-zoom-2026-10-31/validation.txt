코드 글자 크기 유지 수정 및 검증 — 2026-10-31 (Asia/Seoul)

원인: 코드 편집기 글자 크기가 임시 문서 탭 ID에 저장되었고, 새 문서를 활성화하면 해당 ID의 값이 없어 100%를 다시 적용했다.
수정: 코드·일반 텍스트·코드 Git 비교는 공통 code 배율을 저장하고 사용한다. 휠/핀치/위치 표시줄이 같은 값을 변경하며, 분할 화면·다른 창·새 파일·재시작에 적용된다. Markdown, 노트북, 웹, 터미널과 미디어의 개별 확대는 유지한다.

검증: 단위 테스트 701개(97개 파일), 빌드 도구 검사 14개, 타입 검사 및 프로덕션 빌드 통과.
Electron 계약 목록 233개를 전부 검증했다. 확대 관련 21개 통과, 나머지 중 211개 통과, Python 이름 변경 검사 보강 후 해당 1개 통과.
이름 변경 검사에서는 입력창이 닫히자마자 비동기 변경 적용 전에 저장하고 있었다. 변경된 편집 내용 확인을 추가한 후 저장/Undo/디스크 내용 검사를 그대로 유지했다. 제품의 언어 서버 동작은 변경하지 않았다.
최초 통합 명령은 세션 중단으로 종료되어 GUI 부분을 위 두 그룹으로 나누어 완료했다. 자동 재시도, 시나리오 생략, 성능 허용치 변경은 없다.
GUI와 벤치마크는 모두 with-isolated-display.sh로 Xvfb·별도 런타임·D-Bus를 사용하고 상속된 Wayland 연결을 제거했다.
