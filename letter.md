I spent two months trying out the newfound coding technology of ChatGPT 6 Astra, the latest LLM model OpenAI released on September 4th. 

Currently, even without proper prompting (although even prompting it to write clean code does not take that much effort these days), and by just providing popular GitHub repos and describing what kind of software I want, I was able to merge core features of VS Code, Min Browser, Crossnote Markdown editing, and much more. The user interface is seamless enough for me to use this software every day.

Of course, that development strategy makes the actual release of this kind of software harder, with copyright issues that are difficult to resolve. But it shows that within five years, we may have a software ecosystem where users ask AI to build whatever software they have in mind, and AI maintains the software independently, without human intervention. Just like a Christmas present. (All you have to do is pay $100 to OpenAI.) People will not adapt to software that software engineers have spent years crafting; everyone will simply start making their own projects by assembling open-source projects available to everyone. 

What happens when intelligence and mathematical ideas become as abundant as water for everyone? I am under no illusion that I have proved myself to be a brilliant software engineer by making this vibe-coded result.

Another concern for me is that I know nothing about how these 70k+ lines of code actually work, which makes this vibe-coded text editor an easy target for LLM-powered hackers. Nobody will know whether this software is safe, even if it is. There is never going to be a security manager for my own custom code.

But anyway, now I am happy to have my custom vibe-coded text editor just for me, and I actually use it regularly whenever I read .md files or study German (using Git features).
